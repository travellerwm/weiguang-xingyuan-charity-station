# 微光行远——爱心捐助中转站小游戏

> 爱心捐赠，温暖传递。经营一座小小的物资中转站，把每一份善意送到真正需要它的地方。

《微光行远》是一款使用 Godot 制作的 2D 像素风经营策略小游戏。玩家需要接收、整理、处理和配送捐赠物资，在每天有限的物资与不断变化的地区订单之间做出取舍，逐步扩建中转站。

## 玩法说明

玩家经营“爱心捐助中转站”，每天接收捐赠物资，并根据不同地区的需求完成配送。右侧订单会列出当天需要援助的地区；带红色叹号的地区仍有未满足需求，完成全部需求后叹号消失。

物资分为可用、需消毒和需翻新等品质。可用物资可以直接配送，其他物资需要先送往对应功能建筑处理。暂存区负责领取当天的物资；手持物资可以立即配送，也可以归还，归还的物资会自动进入仓库。

随着等级提升，地区订单会从简单的单物资需求逐渐变成多地区、多物资组合。中后期还会出现当天新物资无法完全匹配订单的缺口，需要提前储备关键物资，并通过情报网、调度中心和物流公司进行规划。

## 核心系统

- **订单与匹配**：物资标签越符合地区需求，获得的爱心值和声誉值越高；万能物资可以适配任意需求。
- **仓库管理**：仓库物资可以搬运、锁定或舍弃。可用物资不能直接舍弃，需要先送往审查室处理。
- **物资品质**：需消毒、需翻新的物资不能直接配送；当天未处理的非可用暂存物资会在次日消失。
- **双数值成长**：成功援助可获得爱心值，累计爱心用于升级；已花费的爱心同样计入升级进度。声誉值代表中转站的可信度，未完成订单或未妥善处理物资会影响声誉。
- **商店与建筑**：可以购买仓库扩容、背包、跑鞋、处理额度和物流车辆等升级。
- **阶段解锁**：消毒室在 Lv2、翻新室在 Lv3、审查室在 Lv4、调度中心与情报网在 Lv5、物流公司在 Lv7 解锁。
- **存档与音频**：支持网页端本地存档、读取以及背景音乐和音效调节。

## 每日经营建议

1. 先查看当天订单和暂存区的新物资。
2. 优先配送标签高度匹配的可用物资，以提高爱心和声誉收益。
3. 将需消毒、需翻新的物资送往对应建筑处理。
4. 把暂时用不到但可能在后续订单中出现的关键物资存入仓库并锁定。
5. 推进次日前检查手持物资、暂存区和未完成订单；Lv4 起可用物资未处理会阻止进入次日，Lv5 后未操作的暂存物资会按阶段扣除声誉。

## 设计思路

游戏核心亮点是“物资缺口压力 + 双数值平衡体系”。前期玩家主要学习配送与物资处理规则，稳定完成订单；中期开始管理仓库存货、应对随机需求；后期则需要借助情报和物流能力提前规划。

爱心值和声誉值形成长期取舍：爱心值用于处理物资、购买道具和升级功能，声誉值则代表中转站的社会信任。玩家需要判断是消耗爱心修复物资、保留库存等待更合适的订单，还是承担声誉风险处理低价值物资。

## 技术与工具

- **游戏引擎**：Godot
- **表现形式**：2D 像素风地图与角色
- **主要模块**：角色移动、订单生成与匹配、物资品质处理、仓库管理、商店升级、等级解锁、存档和音频系统
- **发布形式**：Godot Web 导出（HTML5 / WebAssembly）

## 本地运行

仓库中包含已经导出的网页版本。Windows 用户可以直接运行 `启动游戏.bat`（或 `run_game.bat`），也可以在 PowerShell 中运行：

```powershell
.\start_server.ps1
```

随后访问：

```text
http://127.0.0.1:8090/index.html
```

> 浏览器通常不能通过 `file://` 正常加载 WebAssembly，因此请使用本地 HTTP 服务器运行。首次进入页面后点击游戏画面可启用音频。
