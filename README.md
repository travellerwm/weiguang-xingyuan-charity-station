# 微光行远——爱心捐助中转站小游戏

一款以爱心物资接收、处理、储备与配送为核心的 2D 像素风经营小游戏。

## 玩法说明

玩家经营“爱心捐助中转站”，每天接收捐赠物资，并根据不同地区的需求完成配送。物资可能需要消毒、翻新、审查或暂存，玩家需要合理安排仓库、手持物资和功能建筑。

随着等级提升，地区订单会从简单需求逐渐变成多地区、多物资需求。后期还可能出现当日新物资无法完全匹配订单的缺口，玩家需要提前储备并灵活调度。

## 设计思路

游戏核心亮点是“物资缺口压力 + 双数值平衡体系”。前期玩家主要学习配送规则，稳定完成订单；中期开始管理仓库存货，应对随机需求；后期则需要通过情报网、调度中心和物流公司提前规划。

同时，爱心值和声誉值形成双资源取舍：爱心值用于处理物资、购买道具和升级功能，声誉值代表中转站信任度。玩家需要判断是消耗爱心修复物资，还是承担声誉风险处理低价值物资，从而形成长期运营策略。

## 运用技术与工具

项目使用 Godot 制作 2D 像素风地图、角色移动、订单系统、仓库管理、商店升级、存档和音频系统，并导出网页端体验版本。

## 本地运行

这是 Godot 导出的网页版本。Windows 用户可运行 `启动游戏.bat`（或 `run_game.bat`）启动本地服务器并打开游戏，也可以运行：

```powershell
.\start_server.ps1
```

> 浏览器出于安全限制通常不能直接通过 `file://` 正常加载 WebAssembly，因此建议通过本地服务器运行。
