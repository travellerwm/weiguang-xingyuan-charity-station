# 微光行远——爱心捐助中转站小游戏

《微光行远》是一款公益物资中转站模拟经营游戏。玩家需要接收、整理和配送捐赠物资，在不断变化的地区需求中经营并升级自己的中转站。

## 核心玩法

玩家每天接收捐赠物资，并根据不同地区的订单完成配送。随着等级提升，订单会从简单需求逐渐变为多地区、多物资需求。

物资可能需要消毒、翻新、审查或暂存。玩家需要合理安排仓库、手持物资和功能建筑。后期可能出现当天新物资无法完全匹配订单的缺口，需要提前储备并灵活调度。

## 设计思路

游戏的核心是“物资缺口压力 + 双数值平衡体系”。

- 前期学习配送规则，稳定完成订单。
- 中期管理仓库存货，应对随机需求。
- 后期通过情报网、调度中心和物流公司提前规划，防范物资缺口。

爱心值用于处理物资、购买道具和升级功能，声誉值代表中转站的信任度。玩家需要判断是消耗爱心修复物资，还是承担声誉风险处理低价值物资，从而形成长期经营策略。

## 视觉风格

游戏采用暖色调的轻量像素卡通风格，以大地图分区展示不同功能建筑，使用图标呈现物资和订单信息，在公益主题与轻松的经营体验之间保持平衡。

## 操作方式

| 操作 | 按键 |
| --- | --- |
| 移动 | `WASD` 或方向键 |
| 与建筑交互 | `E` |
| 推进次日 | `R` |
| 保存游戏 | `F6` |
| 读取存档 | `F10` |
| 地图缩放 | 鼠标滚轮 |

## 技术与工具

项目使用 Godot 制作，主要包含 2D 像素风地图、角色移动、订单系统、仓库管理、商店升级、存档和音频系统，并导出为网页端体验版本。

## 本地运行

Windows 用户可以运行 `启动游戏.bat` 或 `run_game.bat`，也可以在 PowerShell 中执行：

```powershell
.\start_server.ps1
```

随后访问：

```text
http://127.0.0.1:8090/index.html
```

> 请通过本地 HTTP 服务器运行游戏，不要直接双击 `index.html`，否则浏览器可能无法正常加载 WebAssembly 文件。
